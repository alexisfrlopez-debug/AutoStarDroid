# livrables/ — organisation des livrables

Ce dossier reflète l'organisation du Drive « Autostar » (dossier `livrables/`)
pour plus de clarté :

| Sous-dossier | Contenu |
|---|---|
| `archives/` | Historique des versions (APK et sources) : tout se trouve sur les [Releases GitHub](https://github.com/alexisfrlopez-debug/AutoStarDroid/releases) et dans le Drive `livrables/archives/`. |
| `documents/` | Documents du projet : protocole série (`PROTOCOLE.md`), feuille de route (`ROADMAP.md`). |
| `dernieres-livraisons/` | La livraison courante : voir [Releases/latest](https://github.com/alexisfrlopez-debug/AutoStarDroid/releases/latest) pour l'APK signé, et le Drive `livrables/dernieres-livraisons/` pour l'APK + l'archive source correspondante. |

Les APK eux-mêmes ne sont pas versionnés dans git (`.gitignore`) : ils sont
publiés en release GitHub à chaque tag `v*` et déposés sur le Drive.
