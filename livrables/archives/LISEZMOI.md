# archives/

Historique des livraisons (APK, sources compressées, logs) :

- **Releases GitHub** : chaque tag `vX.Y.Z` possède sa release avec l'APK signé
  → <https://github.com/alexisfrlopez-debug/AutoStarDroid/releases>
- **Drive `livrables/archives/`** : copie complète des APK et archives sources
  des versions passées, plus les logs de crash et les backups.

Ce dossier peut contenir des APK locaux (ignorés par git via `*.apk`).
