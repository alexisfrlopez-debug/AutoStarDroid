# dernieres-livraisons/

La livraison courante d'AutoStarDroid :

- **APK signé** : [Releases/latest](https://github.com/alexisfrlopez-debug/AutoStarDroid/releases/latest)
  (attaché automatiquement par le CI à chaque tag `v*`).
- **Drive** : `livrables/dernieres-livraisons/` contient l'APK et l'archive
  source correspondante.

Aucun binaire n'est stocké ici dans git — ce dossier est le pointeur de la
version en cours.
